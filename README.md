# 다크 섹터 (Dark Sector) PS3 일본판 한글패치

PS3 일본판 「ダークセクター」(**BLJS10021**)용 비공식 한글패치입니다.
게임 안의 텍스트·이미지·자막을 한국어로 바꾸며, **일본어 음성**과 **영어 음성** 중 원하는 쪽으로 플레이할 수 있습니다.
RPCS3에서 테스트했습니다.

- 제작: 용가리 (Yonggary6425)
- 다운로드: 오른쪽 **[Releases](../../releases)**

---

## 왜 일본판에 한글패치를 했나요?

| | 아시아판 (Korea, En/Fr/Es) | **일본판 (BLJS10021)** |
|---|---|---|
| 영어 음성 | O | **O** |
| 일본어 음성(더빙) | X | **O** |
| 음성 선택 | 불가 | **PS3(RPCS3) 시스템 언어로 선택** |

국내 정식 발매판인 아시아판(En/Fr/Es)에는 **영어 음성만** 들어 있습니다.
일본판에는 일본어 더빙과 **영어 음성이 함께** 들어 있고, 게임이 PS3 시스템 언어를 보고 어느 음성을 쓸지 정합니다.

그래서 일본판을 기반으로 하면 **한 게임으로 일본어 음성과 영어 음성을 모두 고를 수 있습니다.**
다만 일본어 음성과 영어 음성은 대사가 조금씩 다릅니다(일본어 더빙이 영어 대본을 그대로 옮긴 것이 아님).
그래서 자막을 음성에 맞춰 **두 가지 판**으로 만들었습니다.

- **일본어 음성판(JPvoice):** 일본어 음성을 받아 적어 그 내용을 번역한 자막. 들리는 일본어 대사와 뜻이 맞습니다.
- **영어 음성판(ENvoice):** 영어 원문 대사를 번역한 자막. 들리는 영어 대사와 뜻이 맞습니다.

메뉴·문서·튜토리얼 등 자막 외 텍스트는 두 판이 같습니다.

## 어떤 판을 받아야 하나요?

| 파일 | 들리는 음성 | 자막 기준 | RPCS3 콘솔 언어 설정 | 결과물 이름 |
|---|---|---|---|---|
| `DarkSector_JP_KOR_v1.0_JPvoice.zip` | **일본어** | 일본어 음성 | **Japanese** | `…_KOR_JPvoice` |
| `DarkSector_JP_KOR_v1.0_ENvoice.zip` | **영어** | 영어 원문 대사 | **English** | `…_KOR_ENvoice` |

- 결과물 이름이 다르므로 두 판을 **모두 만들어 두고** 번갈아 플레이할 수 있습니다.
- 원본 게임은 바뀌지 않습니다. 패처가 원본 옆에 한글패치판을 새로 만듭니다.

## 준비물
1. **일본판 Dark Sector (BLJS10021)** 정품 덤프 — 폴더 형식(`PS3_GAME` 폴더가 있는 형태) 또는 **복호화된(Decrypted) ISO**
2. **RPCS3** (Windows)
3. Windows 10/11 (패처는 기본 내장 PowerShell로 동작, 별도 설치 필요 없음)
4. 여유 공간: 폴더 방식 약 1.6GB / ISO 방식 원본 ISO 크기 + 약 600MB

## 적용 방법 A — 게임 폴더에 적용 (`한글패치_적용.bat`)

1. Releases에서 원하는 판의 zip을 받아 압축을 풉니다.
2. 압축 푼 패치 폴더를 게임 폴더 옆에 둡니다. 예:
   ```
   D:\Games\Dark Sector (Japan)\              ← 원본 게임 폴더 (PS3_GAME 이 들어 있음)
   D:\Games\DarkSector_JP_KOR_v1.0_JPvoice\   ← 압축 푼 패치
   ```
3. **`한글패치_적용.bat`** 을 더블클릭합니다.
   - 게임 폴더를 자동으로 못 찾으면 폴더 선택 창이 뜹니다. 게임 폴더를 bat 파일 위에 끌어다 놓아도 됩니다.
4. 완료되면 원본 옆에 `Dark Sector (Japan)_KOR_JPvoice` (또는 `_KOR_ENvoice`) 폴더가 생깁니다.
5. RPCS3 → `File` → `Add Games` → 새로 생긴 폴더를 선택해 추가합니다.
6. 아래 **「음성별 RPCS3 설정」** 대로 콘솔 언어를 맞추고 실행합니다.

패치를 지우려면 결과물 폴더만 삭제하면 됩니다.

## 적용 방법 B — ISO에 바로 적용 (`한글패치_ISO.bat`)

1. zip을 풀고 **`한글패치_ISO.bat`** 을 실행합니다. (ISO를 bat 위에 끌어다 놓아도 됩니다)
2. 번호를 고릅니다.
   - **1. 한글패치판 ISO 새로 만들기** → `원본이름_KOR_JPvoice.iso` / `_KOR_ENvoice.iso` 생성, 원본 그대로 (권장)
   - **2. 원본 ISO에 바로 덮어쓰기** → 복구 정보 `원본이름.iso.korbak` 생성
   - **3. 덮어쓴 ISO를 원본으로 복구** (2번으로 패치한 경우)
3. RPCS3에 결과 ISO를 추가하고, 아래 설정대로 콘솔 언어를 맞춥니다.

- 바뀐 파일은 ISO 끝에 붙고, 파일 목록(ISO9660/Joliet/UDF)만 새 위치를 가리키게 바뀝니다. 그래서 결과 ISO가 약 600MB 커집니다.
- 원본 데이터가 남아 있어 3번으로 바이트 단위까지 되돌릴 수 있습니다.
- **복호화된(Decrypted) ISO만 지원합니다.**

## 음성별 RPCS3 설정 (중요)

일본판은 **PS3 시스템 언어(RPCS3의 Console Language)** 를 보고 음성을 고릅니다.
설정이 맞지 않으면 일본어 음성판인데 영어가 나오는 등, 음성과 자막이 어긋납니다.

### 게임별 설정 여는 법
1. RPCS3 게임 목록에서 한글패치판 게임을 **오른쪽 클릭**
2. **`Create Custom Configuration`** (이미 만들었다면 `Change Custom Configuration`)
3. **`System`** 탭 → **`Console Language`**
4. 아래 표대로 고르고 **`Save`**

| 플레이하려는 음성 | 사용할 판 | Console Language |
|---|---|---|
| 🇯🇵 일본어 음성 | **JPvoice** | **Japanese** |
| 🇺🇸 영어 음성 | **ENvoice** | **English** |

- 게임별 설정(Custom Configuration)으로 바꾸면 다른 게임에는 영향이 없습니다.
- 영어 음성판(ENvoice)은 일본어 음성 목록을 꺼 두어 Japanese 설정에서도 영어 음성이 나오도록 해 두었지만, 음성이 안 나오거나 이상하면 **English**로 두세요.
- 두 판을 모두 만들었다면 각각 따로 게임별 설정을 해 두면 됩니다.

### 음성이 의도와 다르게 나올 때
- 일본어 판인데 영어가 나온다 → JPvoice 게임의 Console Language가 **Japanese**인지 확인
- 자막이 음성과 뜻이 안 맞는다 → 음성에 맞는 판(JPvoice/ENvoice)을 쓰고 있는지 확인
- 설정을 바꾼 뒤에는 게임을 완전히 종료했다가 다시 실행하세요.

## (선택) 시스템 문구까지 한글화

시작 화면 위쪽의 자동 저장 안내 같은 문구는 실행 파일(EBOOT.BIN) 안에 있습니다.
이 부분까지 한글화하려면 복호화된 실행 파일이 필요합니다.

1. RPCS3 → `Utilities` → **`Decrypt PS3 Binaries`**
2. 원본 게임의 `PS3_GAME\USRDIR\EBOOT.BIN` 을 선택 → 같은 폴더에 **`EBOOT.elf`** 가 생깁니다.
3. 패처를 다시 실행합니다.
   - 폴더 방식: 원본 `USRDIR` 에 `EBOOT.elf` 가 있으면 자동으로 사용합니다.
   - ISO 방식: ISO와 같은 폴더 **또는 그 하위 폴더**(예: 압축 푼 게임 폴더의 `PS3_GAME\USRDIR`)에서 자동으로 찾습니다. "시스템 문구도 한글화할까요?" 에 **Y**.
4. 이렇게 만든 결과물은 **RPCS3 전용**입니다(실기 불가).
   ISO에는 RPCS3가 읽을 수 있는 FSELF 형식으로 들어갑니다.

`EBOOT.elf` 는 파일 지문(SHA1)으로 일본판 원본인지 확인한 뒤에만 사용합니다.

## 처음 실행할 때
- "기존 게임 데이터가 올바르지 않습니다. 복구가 필요합니다" 같은 메시지가 나오면 **정상**입니다.
  파일이 바뀌어 게임이 HDD 캐시 데이터를 다시 만드는 과정이니 그대로 진행하세요.

## 알려진 사항
- 이어하기/챕터 재시작으로 1미션을 시작하면 지명 자막이 나오지 않습니다. 원작도 같은 동작입니다.
- 일부 무전·녹음 음성(예: 초반 프로젝터 브리핑)은 원작에 자막이 없어 자막이 나오지 않습니다.
